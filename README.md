## 1. Опис проєкту

Метою роботи є розгортання робочого середовища та розробка кросплатформного мобільного застосунку з використанням фреймворку **React Native**, платформи **Expo** та файлової навігації **Expo Router**[cite: 5, 6].

У застосунку реалізовано нижню панель навігації (`Tabs`) із 3 функціональними екранами[cite: 5, 6]:
1. **Головна (`index.tsx`)**[cite: 3]: фірмова шапка університету із зазначенням даних автора, поле пошуку та стрічка подій університету з датами й анотаціями[cite: 3].
2. **Фотогалерея (`gallery.tsx`)**[cite: 4]: адаптивна сітка зображень у 2 колонки на основі `FlatList`, панель перемикання режиму відображення та інтеграція фотоматеріалів[cite: 4].
3. **Профіль (`profile.tsx`)**[cite: 5]: персональна картка користувача з банером, аватаром, полями даних (ПІБ, електронна пошта, група) та інтерактивним перемикачем сповіщень (`Switch`)[cite: 5].

## 2. Інструкція із запуску проєкту

### Попередні вимоги
- Встановлений **Node.js** (версія LTS).
- Застосунок **Expo Go** на смартфоні (Android / iOS) або налаштований емулятор.

### Покроковий запуск
1. Клонувати репозиторій:
   ```bash
   git clone [https://github.com/Anna-P-C/MobileLabsRN2026.git](https://github.com/Anna-P-C/MobileLabsRN2026.git)
  1. Перейти до каталогу лабораторної роботи:cd MobileLabsRN2026/lab1
  2.Встановити залежності:npm install
  3.Запустити Metro Bundler:npx expo start
  4.Відсканувати отриманий QR-код через застосунок Expo Go на телефоні.
