# Лабораторна робота №5

## Опис проєкту
Мобільний застосунок **«Файловий менеджер»**, розроблений на React Native з використанням Expo Router та сучасного об'єктно-орієнтованого API бібліотеки `expo-file-system` (`File`, `Directory`, `Paths`).

### Реалізований функціонал:
- **Статистика пам'яті пристрою:** відображення загального, зайнятого та вільного простору сховища смартфона.
- **Файлова навігація:** відображення поточного шляху директорії, виведення списку папок і файлів за допомогою `FlatList`, перехід у вкладені папки та повернення на рівень вгору.
- **Керування об'єктами:** створення нових директорій і текстових файлів (`.txt`) з початковим вмістом через модальні вікна.
- **Перегляд та редагування файлів:** відкриття `.txt` файлів на окремому екрані редактора, модифікація тексту та збереження змін.
- **Видалення з підтвердженням:** видалення файлів і папок після підтвердження через нативний діалог `Alert.alert()`.
- **Детальні властивості:** перегляд назви, типу за розширенням, розміру у байтах та дати останньої модифікації файлу.

### Висновки та відповіді на контрольні запитання
Під час виконання лабораторної роботи було опановано роботу з локальною файловою системою мобільного пристрою засобами сучасного API бібліотеки expo-file-system. 
Реалізовано повноцінну навігацію директоріями, CRUD-операції над файлами та папками, а також отримання метаданих сховища й файлів.
### Які основні директорії надає expo-file-system (documentDirectory та cacheDirectory) і в чому різниця між ними?
documentDirectory (Paths.document) — це постійна папка додатку для важливих даних, які зберігаються постійно, доки їх не видалить сам користувач або не видалять програму. 
cacheDirectory (Paths.cache) — це папка для тимчасових файлів і кешу, яку телефон може автоматично очистити в будь-який момент, коли закінчиться вільна пам'ять.

### Які базові методи expo-file-system використовуються для читання, запису, створення директорій та видалення файлів і папок?
Для читання тексту з файлу використовується метод file.text(), для запису або оновлення вмісту — file.write(). 
Нові папки та файли створюються методами directory.create() і file.create(), а видаляються через file.delete() або directory.delete().

### Як отримати метадані про об'єкт файлової системи (розмір, дату модифікації) та інформацію про пам'ять пристрою?
Розмір файлу та дату його останньої зміни можна дізнатися напряму з властивостей об'єкта File (file.size та file.modificationTime). 
Загальний і вільний обсяг пам'яті смартфона отримується через об'єкт Paths за допомогою властивостей Paths.totalDiskSpace та Paths.availableDiskSpace, а зайнята пам'ять рахується як різниця між ними.
